Exercício 02 — Criação de Consultas em SQL

Considerando o esquema de dados descrito abaixo, que modela um sistema de gestão de estoque, faça a especificação dos comandos SQL para as consultas solicitadas.

Descrição das Entidades

  • CATEGORIA: id_categoria (PK), nome_categoria, descricao.
  • FORNECEDOR: id_fornecedor (PK), nome_fornecedor, cnpj, telefone, email, endereco.
  • PRODUTO: id_produto (PK), codigo_produto (Unique), nome_produto, descricao, preco_custo, preco_venda, estoque_minimo, estoque_atual, id_categoria (FK), id_fornecedor (FK).
  • DEPOSITO: id_deposito (PK), nome_deposito, localizacao.
  • ESTOQUE_DEPOSITO: id_estoque (PK), id_produto (FK), id_deposito (FK), quantidade.
  • CLIENTE: id_cliente (PK), nome_cliente, cpf_cnpj, telefone, email, endereco.
  • USUARIO: id_usuario (PK), login, senha_hash, nome_completo, ativo.
  • ORDEM_COMPRA: id_ordem_compra (PK), data_emissao, data_previsao, status, valor_total, id_fornecedor (FK).
  • ITEM_ORDEM_COMPRA: id_item_compra (PK), id_ordem_compra (FK), id_produto (FK), quantidade, valor_unitario, subtotal.
  • PEDIDO_VENDA: id_pedido_venda (PK), data_pedido, status, valor_total, id_cliente (FK), id_usuario (FK).
  • ITEM_PEDIDO_VENDA: id_item_venda (PK), id_pedido_venda (FK), id_produto (FK), quantidade, valor_unitario, subtotal.
  • MOVIMENTACAO: id_movimentacao (PK), data_movimentacao, tipo_movimentacao, quantidade, id_produto (FK), id_deposito_origem (FK), id_deposito_destino (FK), id_usuario (FK), observacao.

Relacionamentos

  • Uma Categoria possui N Produtos (1:N).
  • Um Fornecedor fornece N Produtos (1:N).
  • Um Produto possui estoque em N Depósitos (N:N).
  • Um Fornecedor recebe N Ordens de Compra (1:N).
  • Uma Ordem de Compra possui N Itens (1:N).
  • Um Cliente realiza N Pedidos de Venda (1:N).
  • Um Pedido de Venda possui N Itens (1:N).
  • Um Usuário registra N Movimentações e N Pedidos de Venda.
  • Uma Movimentação refere-se a um Produto e pode envolver um ou dois Depósitos.

Consultas

Consulta 1 — Produtos com Estoque Abaixo do Mínimo

Esta consulta deve utilizar a tabela produto, selecionando apenas os produtos que têm estoque atual abaixo do mínimo, e deve projetar o seu código, nome, estoque atual e mínimo.

Consulta 2 — Posição de Estoque por Depósito

Esta consulta deve utilizar as tabelas estoque_deposito, deposito e produto, exibindo apenas as posições com quantidade maior que zero, e deve projetar o nome do depósito, o nome do produto e a quantidade disponível.

Consulta 3 — Top 5 Produtos Mais Vendidos

Esta consulta deve utilizar as tabelas item_pedido_venda e produto, contando quantas vezes cada produto foi incluído em pedidos de venda, e deve retornar apenas os cinco produtos com maior frequência de venda.

Consulta 4 — Valor Total em Estoque por Depósito com Média de Preços

Esta consulta deve utilizar as tabelas deposito, estoque_deposito e produto, considerando apenas posições com quantidade maior que zero, e deve retornar por depósito o número de produtos distintos armazenados, a quantidade total de itens, o valor total em estoque e o preço médio dos produtos.

Consulta 5 — Usuários e Volume de Movimentações Registradas (incluindo usuários sem registros)

Esta consulta deve utilizar as tabelas usuario e movimentacao, garantindo que usuários sem movimentações também apareçam no resultado, e deve retornar por usuário o total de movimentações realizadas, o volume total de itens movimentados e a quantidade de produtos e tipos de operação distintos.

Dump para criar banco de dados 

CREATE DATABASE IF NOT EXISTS ex02;
USE ex02;

CREATE TABLE categoria (
    id_categoria INT AUTO_INCREMENT PRIMARY KEY,
    nome_categoria VARCHAR(100) NOT NULL, 
    descricao TEXT
) ENGINE=InnoDB;

CREATE TABLE fornecedor (
    id_fornecedor INT AUTO_INCREMENT PRIMARY KEY,
    nome_fornecedor VARCHAR(150) NOT NULL, 
    cnpj VARCHAR(20) UNIQUE NOT NULL,
    telefone VARCHAR(20), 
    email VARCHAR(100),
    endereco TEXT
) ENGINE=InnoDB;

CREATE TABLE cliente (
    id_cliente INT AUTO_INCREMENT PRIMARY KEY, 
    nome_cliente VARCHAR(150) NOT NULL, 
    cpf_cnpj VARCHAR(20) UNIQUE NOT NULL,
    telefone VARCHAR(20),
    mail VARCHAR(100),
    endereco TEXT
) ENGINE=InnoDB;

CREATE TABLE usuario (
    id_usuario INT AUTO_INCREMENT PRIMARY KEY, 
    login VARCHAR(50) UNIQUE NOT NULL,
    senha_hash VARCHAR(255) NOT NULL, 
    nome_completo VARCHAR(100) NOT NULL, 
    ativo BOOLEAN DEFAULT TRUE
) ENGINE=InnoDB;

CREATE TABLE deposito (
    id_deposito INT AUTO_INCREMENT PRIMARY KEY, 
    nome_deposito VARCHAR(100) NOT NULL, 
    localizacao VARCHAR(200)
) ENGINE=InnoDB;

CREATE TABLE produto (
    id_produto INT AUTO_INCREMENT PRIMARY KEY, 
    codigo_produto VARCHAR(50) UNIQUE NOT NULL, 
    nome_produto VARCHAR(150) NOT NULL, 
    descricao TEXT,
    preco_custo DECIMAL(10,2) CHECK (preco_custo >= 0), 
    preco_venda DECIMAL(10,2) CHECK (preco_venda >= 0), 
    estoque_minimo INTEGER DEFAULT 0 CHECK (estoque_minimo >= 0),
    estoque_atual INTEGER DEFAULT 0, 
    id_categoria INTEGER,
    id_fornecedor INTEGER,
    FOREIGN KEY (id_categoria) REFERENCES categoria(id_categoria),
    FOREIGN KEY (id_fornecedor) REFERENCES fornecedor(id_fornecedor)
) ENGINE=InnoDB;

CREATE TABLE estoque_deposito (
    id_estoque INT AUTO_INCREMENT PRIMARY KEY,
    id_produto INTEGER NOT NULL, 
    id_deposito INTEGER NOT NULL, 
    quantidade INTEGER NOT NULL DEFAULT 0 CHECK (quantidade >= 0), 
    UNIQUE(id_produto, id_deposito),
    FOREIGN KEY (id_produto) REFERENCES produto(id_produto),
    FOREIGN KEY (id_deposito) REFERENCES deposito(id_deposito)
) ENGINE=InnoDB;

CREATE TABLE ordem_compra (
    id_ordem_compra INT AUTO_INCREMENT PRIMARY KEY,
    id_fornecedor INTEGER NOT NULL, 
    data_emissao TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    data_previsao DATE,
    status VARCHAR(20) CHECK (status IN ('PENDENTE', 'RECEBIDO', 'CANCELADO')) DEFAULT 'PENDENTE',
    valor_total DECIMAL(12,2) DEFAULT 0,
    FOREIGN KEY (id_fornecedor) REFERENCES fornecedor(id_fornecedor)
) ENGINE=InnoDB;

CREATE TABLE item_ordem_compra (
    id_item_compra INT AUTO_INCREMENT PRIMARY KEY,
    id_ordem_compra INTEGER NOT NULL,
    id_produto INTEGER NOT NULL, 
    quantidade INTEGER NOT NULL CHECK (quantidade > 0), 
    valor_unitario DECIMAL(10,2) NOT NULL CHECK (valor_unitario >= 0),
    subtotal DECIMAL(12,2) GENERATED ALWAYS AS (quantidade * valor_unitario) STORED,
    FOREIGN KEY (id_ordem_compra) REFERENCES ordem_compra(id_ordem_compra) ON DELETE CASCADE,
    FOREIGN KEY (id_produto) REFERENCES produto(id_produto)
) ENGINE=InnoDB;

CREATE TABLE pedido_venda (
    id_pedido_venda INT AUTO_INCREMENT PRIMARY KEY,
    id_cliente INTEGER NOT NULL, 
    id_usuario INTEGER NOT NULL, 
    data_pedido TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    status VARCHAR(20) CHECK (status IN ('ABERTO', 'CONFIRMADO', 'FATURADO', 'CANCELADO')) DEFAULT 'ABERTO',
    valor_total DECIMAL(12,2) DEFAULT 0,
    FOREIGN KEY (id_cliente) REFERENCES cliente(id_cliente),
    FOREIGN KEY (id_usuario) REFERENCES usuario(id_usuario)
) ENGINE=InnoDB;

CREATE TABLE item_pedido_venda (
    id_item_venda INT AUTO_INCREMENT PRIMARY KEY,
    id_pedido_venda INTEGER NOT NULL,
    id_produto INTEGER NOT NULL, 
    quantidade INTEGER NOT NULL CHECK (quantidade > 0), 
    valor_unitario DECIMAL(10,2) NOT NULL CHECK (valor_unitario >= 0),
    subtotal DECIMAL(12,2) GENERATED ALWAYS AS (quantidade * valor_unitario) STORED,
    FOREIGN KEY (id_pedido_venda) REFERENCES pedido_venda(id_pedido_venda) ON DELETE CASCADE,
    FOREIGN KEY (id_produto) REFERENCES produto(id_produto)
) ENGINE=InnoDB;

CREATE TABLE movimentacao (
    id_movimentacao INT AUTO_INCREMENT PRIMARY KEY,
    data_movimentacao TIMESTAMP DEFAULT CURRENT_TIMESTAMP, 
    tipo_movimentacao VARCHAR(20) CHECK (tipo_movimentacao IN ('ENTRADA', 'SAIDA', 'TRANSFERENCIA', 'RESERVA', 'BAIXA_RESERVA')),
    quantidade INTEGER NOT NULL CHECK (quantidade > 0), 
    id_produto INTEGER NOT NULL, 
    id_deposito_origem INTEGER, 
    id_deposito_destino INTEGER, 
    id_usuario INTEGER NOT NULL, 
    observacao TEXT,
    FOREIGN KEY (id_produto) REFERENCES produto(id_produto),
    FOREIGN KEY (id_deposito_origem) REFERENCES deposito(id_deposito),
    FOREIGN KEY (id_deposito_destino) REFERENCES deposito(id_deposito),
    FOREIGN KEY (id_usuario) REFERENCES usuario(id_usuario),
    CONSTRAINT check_origem_destino CHECK (
        (tipo_movimentacao = 'ENTRADA' AND id_deposito_origem IS NULL AND id_deposito_destino IS NOT NULL) OR
        (tipo_movimentacao = 'SAIDA' AND id_deposito_origem IS NOT NULL AND id_deposito_destino IS NULL) OR
        (tipo_movimentacao = 'TRANSFERENCIA' AND id_deposito_origem IS NOT NULL AND id_deposito_destino IS NOT NULL) OR
        (tipo_movimentacao IN ('RESERVA', 'BAIXA_RESERVA') AND id_deposito_origem IS NOT NULL)
    )
) ENGINE=InnoDB;
