Questão 7

Saída impressa:

[15, 15, 35, 35, 55, 55, 75, 75, 95, 95]
Soma total: 550

Justificação:

  • Nos índices pares (0, 2, 4, 6, 8), é somado 5 ao valor do elemento.
  • Nos índices ímpares (1, 3, 5, 7, 9), é subtraído 5 ao valor do elemento.
  • A soma total permanece 550, pois cada acréscimo de 5 num elemento é anulado pela subtração de 5 no elemento seguinte.

Parte 4 — Protocolo HTTP, Cliente-Servidor e URL

Questão 11

Questão 12

  1. Front-end (JavaScript / Navegador): O usuário acessa a tela "Meus dados". O JavaScript dispara uma requisição HTTP assíncrona (por exemplo, via fetch) para a API do back-end.
  2. Back-end (Java / Spring Boot): O controlador (Controller) recebe a requisição HTTP, valida-a e chama a camada de serviço/repositório, que executa uma consulta no banco de dados MySQL.
  3. Banco de Dados (MySQL): Processa a instrução SQL na tabela Espiao, recupera o registro correspondente e devolve os dados brutos ao back-end.
  4. Retorno do Back-end: O Spring Boot recebe os dados do banco, mapeia-os para um objeto/DTO, serializa-o no formato JSON e envia-o de volta na resposta HTTP com código de status 200 OK.
  5. Exibição no Front-end: O JavaScript recebe a resposta JSON e atualiza dinamicamente o DOM (HTML) da tela para apresentar as informações do espião.

Parte 5 — Spring Boot

Questão 13

  • Para que serve: O arquivo application.properties é o arquivo central de configuração do Spring Boot. Serve para definir parâmetros de ambiente da aplicação, como as credenciais e URL do banco de dados, porta do servidor web, níveis de log, entre outros.
  • Se a senha estiver incorreta: A aplicação falhará ao tentar conectar no banco de dados MySQL, lançando uma exceção de autenticação (ex.: Access denied for user). Como consequência, qualquer requisição que dependa de dados do banco falhará e retornará um erro ao cliente (ou a aplicação não conseguirá inicializar se houver validação na inicialização).

Questão 14

  • (1) @RestController
  • (2) @GetMapping

Explicação:

  • @RestController: Marca a classe como um controlador REST do Spring, indicando que os valores retornados pelos seus métodos devem ser serializados diretamente no corpo da resposta HTTP (geralmente em formato JSON).
  • @GetMapping: Mapeia requisições HTTP do tipo GET no endpoint especificado (/missoes) para execução do método listarMissoes().
